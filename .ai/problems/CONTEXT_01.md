У нас есть работающий модуль - проверяет сообщения в телеграмм группах по словарю со сложной системой парсинга сообщений на вхождение слов. 
Нужно сохранить работоспособность модуля при этом расширить и переписать следующее:

1) Logging везде
2) Запуск и инициализация через cli - выгрузка конфига, проверка конфига, старт мониторинга.
3) Pydantic модели вместо фиксированный переменных, если где-то есть
4) Отдельный класс для ошибок
5) Дополнительные тесты
6) Расширение документации - более развренутая и качественная документация по работе, установке и настройке
